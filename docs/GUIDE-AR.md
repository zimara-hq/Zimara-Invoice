# دليل تشغيل زيمارا خطوة بخطوة

هذا الدليل يشرح لك وش تسوي بالترتيب: من تشغيل النظام على جهازك، إلى قاعدة البيانات، والاستضافة، والدومين، والربط مع الهيئة، والمتطلبات النظامية قبل ما تبيع لأول عميل.

---

## 1. وش موجود في المستودع

| المجلد | وش فيه |
|---|---|
| `src/app` | صفحات الموقع والنظام (Next.js): الصفحة الرئيسية، التسجيل والدخول، لوحة التحكم، الفواتير، العملاء، المنتجات، التقارير، سجل التدقيق، الاشتراك، الإعدادات، الصفحات القانونية |
| `src/lib/zatca` | محرك الفوترة: XML بمعيار UBL 2.1، التوقيع الرقمي secp256k1، رمز QR، سلسلة البصمات، طلب الشهادة CSR، والاتصال بمنصة فاتورة |
| `src/lib/invoicing.ts` | إصدار المستندات وإرسالها للهيئة داخل معاملة قاعدة بيانات واحدة |
| `src/lib/onboarding.ts` | تسجيل وحدة الإصدار وفحوصات الامتثال الستة |
| `db/migrations` | تصميم قاعدة البيانات، ومعه قيود تمنع تعديل أو حذف الفواتير وسجل التدقيق |
| `tests` | اختبارات المحرك وقاعدة البيانات، واختبار المتصفح الكامل |
| `Dockerfile` و`docker-compose.yml` و`deploy/` | ملفات النشر |
| `prototype/` | النسخة التجريبية الأولى (صفحة وحدة) للاطلاع فقط |

## 2. شغّله على جهازك (أول مرة)

تحتاج: Node.js 22، وPostgreSQL 16، وGit.

```bash
git clone https://github.com/zimara-hq/Zimara-Invoice.git
cd Zimara-Invoice
npm install
cp .env.example .env
```

افتح ملف `.env` وعبّي:

- `DATABASE_URL`: رابط قاعدة البيانات على جهازك، مثل `postgresql://postgres:كلمة_المرور@localhost:5432/zimara`
- `ZIMARA_KEY_ENCRYPTION_KEY`: مفتاح التشفير. ولّده بهذا الأمر وانسخ الناتج:
  ```bash
  node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
  ```
  **مهم جداً:** احفظ هذا المفتاح في مكان آمن. إذا ضاع، ما تقدر تفك مفاتيح التوقيع، وبتحتاج تسجل وحدات إصدار جديدة.

بعدها:

```bash
createdb zimara          # إنشاء قاعدة البيانات
npm run db:migrate       # بناء الجداول
npm run dev              # تشغيل النظام
```

افتح `http://localhost:3000` وسجّل حساب. رابط تأكيد البريد بيطلع لك في نافذة الأوامر (لأن البريد غير مربوط في وضع التطوير).

### تشغيل الاختبارات

```bash
npm test                                              # اختبارات المحرك (وقاعدة البيانات إذا ضبطت TEST_DATABASE_URL)
TEST_DATABASE_URL=postgresql://...zimara_test npm test # مع اختبارات قاعدة البيانات
npm run zatca:sandbox-check                           # اختبار حي مع بوابة مطوري الهيئة (يحتاج إنترنت)
```

## 3. قاعدة البيانات: وين أسويها؟

**المطلوب:** PostgreSQL 16 أو أحدث، **داخل المملكة**. السبب: نظام حماية البيانات الشخصية يقيّد نقل البيانات الشخصية لخارج المملكة، وفواتيرك فيها بيانات عملاء. وكونها داخل المملكة نقطة بيع قوية (وافِق يسوقون فيها).

الخيارات من الأسهل للأقوى:

| الخيار | المنطقة | متى يناسبك | التكلفة التقريبية |
|---|---|---|---|
| **Google Cloud SQL for PostgreSQL** | الدمام `me-central2` | الخيار المقترح. نسخ احتياطي تلقائي وتحديثات أمنية بدون ما تدير خادم | من 200 إلى 450 ريال شهرياً للبداية |
| خادم VPS داخل المملكة (STC Cloud أو Oracle جدة/الرياض) مع `docker-compose.yml` | داخل المملكة | إذا تبي أرخص بداية وعندك خبرة بسيطة بالخوادم | من 150 إلى 400 ريال شهرياً للخادم كله |
| Oracle Cloud Database for PostgreSQL | جدة أو الرياض | إذا اخترت Oracle للاستضافة | حسب الحجم |

**خطوات Google Cloud SQL:**
1. افتح حساب على `console.cloud.google.com` وأنشئ مشروع اسمه `zimara-prod`.
2. من قائمة SQL اختر Create instance ثم PostgreSQL 16.
3. المنطقة: `me-central2 (Dammam)`. فعّل Automated backups وPoint-in-time recovery.
4. أنشئ قاعدة بيانات اسمها `zimara` ومستخدم اسمه `zimara` بكلمة مرور قوية.
5. انسخ رابط الاتصال وحطه في `DATABASE_URL`، وخل `DATABASE_SSL=true`.
6. شغّل `npm run db:migrate` مرة وحدة (أو خله يشتغل تلقائياً مع تشغيل الحاوية، وهذا مضبوط في `Dockerfile`).

## 4. الاستضافة: وين أرفع النظام؟

### الخيار المقترح: Google Cloud Run (الدمام)

ما تدير خوادم، ويكبر تلقائياً مع عدد العملاء، وتدفع حسب الاستخدام.

1. فعّل Cloud Run وArtifact Registry وSecret Manager في مشروعك.
2. حط القيم السرية (`ZIMARA_KEY_ENCRYPTION_KEY` و`DATABASE_URL` و`SMTP_URL` و`CRON_SECRET` و`ANTHROPIC_API_KEY`) في **Secret Manager**، مو في الكود أبداً.
3. من جهازك (بعد تثبيت `gcloud`):
   ```bash
   gcloud run deploy zimara --source . --region me-central2 --allow-unauthenticated \
     --set-secrets=ZIMARA_KEY_ENCRYPTION_KEY=zimara-kek:latest,DATABASE_URL=zimara-db:latest,SMTP_URL=zimara-smtp:latest,CRON_SECRET=zimara-cron:latest \
     --set-env-vars=APP_URL=https://app.zimara.co,DATABASE_SSL=true
   ```
4. اربط Cloud Run بقاعدة البيانات عبر Cloud SQL connector أو اتصال خاص (Private IP).
5. **مهمة إعادة الإرسال:** من Cloud Scheduler أنشئ مهمة كل 10 دقائق ترسل `POST https://app.zimara.co/api/cron/zatca` مع الترويسة `Authorization: Bearer <CRON_SECRET>`. هذي تضمن مشاركة الفواتير المبسطة خلال 24 ساعة حتى لو تعطلت منصة فاتورة.

### الخيار الأرخص: خادم واحد داخل المملكة

1. استأجر خادم Ubuntu داخل المملكة (2 معالج و4 جيجا ذاكرة تكفي للبداية).
2. ثبّت Docker، وانسخ المستودع إلى `/opt/zimara`.
3. `cp .env.example .env` وعبّي القيم، وأضف `POSTGRES_PASSWORD`.
4. عدّل الدومين في `deploy/Caddyfile`.
5. `docker compose up -d --build`. هذا يشغل قاعدة البيانات والنظام وشهادة HTTPS ومهمة إعادة الإرسال.
6. فعّل النسخ الاحتياطي اليومي: `deploy/backup.sh` في cron، وانسخ الملف لمكان ثاني خارج الخادم.

## 5. الدومين والبريد

1. **الدومين:** عندك `zimara.co`. خل الموقع على `zimara.co` والنظام على `app.zimara.co` (سجل A أو CNAME يشير للاستضافة).
2. **البريد:** تحتاج مزود SMTP لرسائل تأكيد البريد واسترجاع كلمة المرور. مثلاً Google Workspace على `zimara.co`، أو أي مزود بريد معاملات. حط الرابط في `SMTP_URL` بهذا الشكل: `smtp://المستخدم:كلمة_المرور@الخادم:587`.
3. أضف سجلات SPF وDKIM وDMARC للدومين عشان ما تروح رسائلك للبريد المزعج.

## 6. الربط مع هيئة الزكاة والضريبة والجمارك

النظام فيه أربع بيئات، تمشي فيها بالترتيب:

| البيئة | وش هي | وش تحتاج |
|---|---|---|
| **محاكاة محلية** | تجربة كاملة داخل زيمارا بدون الهيئة | ولا شي، أي 6 أرقام |
| **بوابة المطورين** | بيئة اختبار الهيئة المفتوحة | رمز OTP الثابت `123345` |
| **المحاكاة (فاتورة)** | نسخة مطابقة للإنتاج | حساب منشأتك في بوابة فاتورة ورمز OTP من بيئة المحاكاة |
| **الإنتاج** | الفواتير الحقيقية | رمز OTP من بوابة فاتورة الرسمية، و`ZATCA_ALLOW_PRODUCTION=true` |

**الخطوات اللي عليك:**
1. شغّل `npm run zatca:sandbox-check` من جهاز متصل بالإنترنت. الاختبار يطلب شهادة امتثال حقيقية من بوابة المطورين، ويرسل فاتورة ضريبية ومبسطة موقّعة، ويطبع رد الهيئة. **إذا ظهرت أخطاء أو تحذيرات في التوقيع، أرسلها لي وأعدلها.** هذي الخطوة الوحيدة اللي ما قدرت أجربها من بيئتي، لأن خوادم الهيئة غير متاحة منها.
2. بعد ما يعدّي، سجّل منشأتك في بيئة **المحاكاة** من صفحة «الربط مع الهيئة» برمز OTP حقيقي.
3. أصدر عدة فواتير تجريبية وتأكد إنها تنعتمد وتنشارك.
4. فعّل `ZATCA_ALLOW_PRODUCTION=true` وسجّل وحدة إنتاج.
5. **التأهيل في القائمة الاسترشادية:** من موقع الهيئة، تبويب «مزودو حلول الفوترة الإلكترونية»، قدّم طلب التأهيل للمرحلة الثانية بسجلك التجاري. القائمة غير ملزمة، لكنها اللي يقصدها المنافسين بكلمة «معتمد من الهيئة».

## 7. المتطلبات النظامية قبل أول عميل يدفع

| المتطلب | الجهة | وش تسوي |
|---|---|---|
| السجل التجاري بنشاط تقنية المعلومات / البرمجيات | وزارة التجارة | استكمال حجز الاسم «زيمارا» وإصدار السجل |
| التسجيل في ضريبة القيمة المضافة | هيئة الزكاة | إلزامي إذا تجاوزت إيراداتك 375,000 ريال سنوياً، واختياري من 187,500 |
| عرض بيانات المنشأة في الموقع | نظام التجارة الإلكترونية | عبّي `COMPANY_LEGAL_NAME` و`COMPANY_CRN` و`COMPANY_VAT` و`COMPANY_ADDRESS`، وتظهر تلقائياً في أسفل الموقع |
| مراجعة الشروط والخصوصية | محامٍ مرخص | الصفحات في `src/app/legal` مكتوبة كمسودة شاملة. بعد مراجعتها فعّل `LEGAL_REVIEWED=true` وأعد البناء |
| نظام حماية البيانات الشخصية | سدايا | الاستضافة داخل المملكة، وسياسة الخصوصية، وإجراء لطلبات الحقوق خلال 30 يوم. تحقق إذا يلزمك التسجيل في منصة حوكمة البيانات الوطنية |
| الأمن السيبراني | الهيئة الوطنية للأمن السيبراني | إذا عملاؤك جهات حكومية أو بنية تحتية حساسة، تحتاج الالتزام بالضوابط الأساسية (ECC) وضوابط الحوسبة السحابية (CCC) |
| بوابة الدفع | البنك المركزي السعودي | اختر بوابة مرخصة (مثل Moyasar أو Tap أو HyperPay) بسجل الشركة. ربطها هو الخطوة الجاية في التطوير |
| فحص اختراق | جهة مستقلة | قبل الإطلاق التجاري |

## 8. ترتيب العمل المقترح لك

1. **هذا الأسبوع:** شغّل النظام على جهازك، وجرّبه بالمحاكاة المحلية، وشغّل `npm run zatca:sandbox-check` وأرسل لي النتيجة.
2. **بالتوازي:** استكمل السجل التجاري والحساب البنكي للشركة.
3. **الأسبوع الجاي:** افتح حساب Google Cloud، وأنشئ قاعدة البيانات في الدمام، وانشر النظام على `app.zimara.co`.
4. **بعد السجل:** سجّل في بوابة فاتورة، واختبر بيئة المحاكاة، وقدّم طلب التأهيل.
5. **قبل البيع:** مراجعة المحامي، وبوابة الدفع، وفحص الاختراق.
